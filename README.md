# VBAを5日で身につけるための課題集

---

## 📘 1日目：VBAの基礎とマクロ記録  
### 到達目標  
VBAの仕組みを理解し、簡単な処理を自動化できる。

### 学習内容  
- VBAとは何か  
- 開発タブの表示  
- マクロ記録の使い方  
- VBAエディタ（VBE）の基本操作

### 実践課題  
- マクロ記録で以下を自動化  
  - A1に「こんにちは」と入力  
  - A1を太字にする  
  - 行の高さを20に変更  
- 記録されたコードにコメントを付ける

### 発展課題  
- A1 → B2 に変更  
- 文字色を赤に変更

---

## 📗 2日目：変数・制御構文（If / For）  
### 到達目標  
簡単なロジックを組めるようになる。

### 学習内容  
- 変数（Dim）  
- If文  
- For / For Each

### 実践課題  
- A1〜A10に1〜10を自動入力  
- A列の値が5以上なら背景色を黄色にする

### 発展課題  
- For Eachで選択範囲だけ処理  
- 偶数→青、奇数→緑に色分け

---

## 📙 3日目：Range操作とワークシート操作  
### 到達目標  
セル・シートを自在に扱えるようになる。

### 学習内容  
- Range / Cells  
- Worksheets  
- 値の取得・代入  
- 行列のInsert / Delete

### 実践課題  
- Sheet2のA1〜A5に果物名を書き込む  
- Sheet1のA列の空白行を削除

### 発展課題  
- Sheet1のデータをSheet2にコピー  
- 最終行を取得して可変データに対応

---

## 📕 4日目：Sub / Function  
### 到達目標  
処理を部品化し、再利用できるようになる。

### 学習内容  
- Subプロシージャ  
- Functionプロシージャ  
- 引数  
- コードの分割

### 実践課題  
- メッセージを表示するSub  
- 2つの数値を足して返すFunction  
- Functionの結果をセルに書き込む

### 発展課題  
- 指定列の合計を返すFunction  
- 指定文字列を含む行だけ抽出するSub

---

## 📓 5日目：実務レベルのミニアプリ作成  
### 到達目標  
実務で使えるレベルのVBAを自力で組める。

### 学習内容  
- MsgBox / InputBox  
- エラー処理  
- 実務でよく使う処理（フィルタ、コピー、ループ）

### 実践課題（ミニアプリ）  
**「売上データ整理ツール」を作成する**  
- Sheet1の売上データを読み込む  
- 売上1万円以上の行をSheet2へコピー  
- 日付順に並べ替え  
- 完了したらMsgBoxで通知

### 発展課題  
- InputBoxで閾値を入力  
- 数字以外なら警告  
- ボタンでワンクリック実行

---

## 学習効果を最大化するコツ  
- 毎日必ずコードを書く  
- 動かないコードを直す経験が最重要  
- 完璧より「動くもの」を優先  
- 実務利用を想像しながら学ぶ
